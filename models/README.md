# Modelo de estimação de pose

O arquivo esperado é `pose_landmarker_lite.task`, fornecido pelo Google para o MediaPipe Pose Landmarker.

Execute, na raiz do projeto:

```bash
python scripts/download_model.py
```

Origem: https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task

- Tamanho: 5.777.746 bytes.
- SHA-256: `59929e1d1ee95287735ddd833b19cf4ac46d29bc7afddbbf6753c459690d574a`.

O script também verifica o modelo quando o arquivo já existe. O binário fica fora do versionamento; as referências e os direitos sobre o modelo permanecem com seus respectivos titulares.
