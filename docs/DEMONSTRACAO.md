# Apresentar o detector de pose

Uma gravação de 30 a 60 segundos pode mostrar o funcionamento com clareza. Use um ambiente iluminado e enquadre o corpo inteiro. Inicie o programa e selecione sua janela no gravador de tela.

Comece parado e movimente os braços, vire levemente o corpo e dê um passo para o lado. Mostre como os pontos acompanham as articulações e como o desenho muda quando uma parte do corpo sai do enquadramento. Preserve tempo suficiente para o observador acompanhar as marcações.

Uma explicação curta pode ser:

> Desenvolvi esta aplicação em Python para visualizar a estimação de pose corporal pela webcam. O MediaPipe fornece os pontos de referência, e o OpenCV faz a captura e o desenho do esqueleto. A visualização foi a base para um projeto posterior de reconhecimento e contagem do movimento de sentar e levantar.

O vídeo demonstra a execução do programa, sem estabelecer uma medida de precisão. Quando estiver pronto, seu link poderá ser incluído no README e na seção Projetos do LinkedIn.

Para encerrar o detector, clique na janela e pressione Q ou Esc. A gravação é feita pelo gravador de tela; o detector não salva vídeo automaticamente.
